    選 Claude 剪好的影片，預覽區就會對到每一格的實際畫面。影片只在你的瀏覽器裡播放，不會上傳。

    3. 剪片時請 Claude 這樣輸出

    剪完後，請另外給我這支片的時間軸 JSON，我要貼進「剪輯回饋台」微調：
{ "project": 片名, "fps": 幀率, "width": 寬, "height": 高,
  "clips": [ { "id", "name": 鏡頭描述, "src": 素材檔名,
               "in": 素材入點格數, "out": 素材出點格數（不含） } ],
  "markers": [ { "id", "clip": 鏡頭 id, "at": 鏡頭內第幾格,
                 "type": 特效種類, "note": 說明 } ] }
鏡頭依成片順序排列。
