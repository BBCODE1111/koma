# Koma 影格

逐格微調 Claude 剪好的影片：把想改的地方整理成可以直接貼回 Claude 的修改提示詞，或匯出時間軸到剪輯軟體。

> Koma 是獨立的開放工具，非 Anthropic 官方產品。

## 功能

- **逐格修剪**：拖鏡頭兩側的邊，或用 ±1 / ±5 調整入點、出點，後面的鏡頭自動順移
- **調整結構**：拖曳或用按鈕移動鏡頭（字幕和特效跟著走）、在鏡頭之間插入新片段、刪除單格、分割、指定換畫面，提示詞都會寫清楚
- **特效標記**：13 種特效，每種都有動畫預覽，可寫下想要的效果
- **修改提示詞**：自動整理成修改清單，一鍵複製給 Claude
- **匯入**：Koma JSON、FCPXML、EDL，或用 `#koma=` 連結開啟
- **匯出**：FCPXML 1.9（Final Cut Pro 10.6 以上、DaVinci Resolve）、EDL（Premiere Pro、DaVinci、Avid）、Koma JSON
- **手動操作清單**：給不能匯入工程的軟體（例如剪映），照清單由後往前逐項修改
- **本機處理**：影片只在瀏覽器裡播放，不會上傳；修改暫存在瀏覽器的 localStorage

調色、字卡和動態特效不會帶到剪輯軟體，只有剪接點和標記。匯入支援單軌直切；空白、轉場、變速和連接片段不會保留，匯入時會列出來。

> **公開測試版**。FCPXML 依 Apple 1.9 DTD 撰寫，審核紀錄在 `docs/reviews/`；尚未在真實剪輯軟體上完成匯入驗證。

## 使用

直接用瀏覽器打開 `index.html`，或啟動本機伺服器：

```bash
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000>。不需要安裝或編譯。介面字型從 Google Fonts 載入，離線時會改用系統字型。

1. 把成片影片和時間軸檔拖進頁面（可先試 `examples/sample.koma.json`）
2. 修剪鏡頭、按 `M` 加特效
3. 在「修改清單」按「複製給 Claude」，或到「匯出到剪輯軟體」下載檔案

「匯入」分頁裡有一段給 Claude 的指令，貼到專案指示後，Claude 每次剪片都會附上 Koma 時間軸。

## 時間軸格式

```json
{
  "project": "片名",
  "fps": 30,
  "width": 1080,
  "height": 1920,
  "clips": [
    { "id": "c1", "name": "鏡頭描述", "src": "IMG_2041.MOV", "in": 45, "out": 117, "note": "" }
  ],
  "markers": [
    { "id": "m1", "clip": "c1", "at": 0, "type": "flash", "note": "開頭閃白一格" }
  ]
}
```

- 鏡頭依成片順序排列
- `in`、`out` 是素材時間，一律以成片的 `fps` 計算，`out` 不含該格
- `srcDuration` 選填，是素材總長（同樣以成片 `fps` 計算），延長超過時 Koma 會警告
- `at` 是該鏡頭內的第幾格。標記跟著素材格走；如果那一格被裁掉，標記會移到鏡頭邊界，之後再延長也不會回去，按復原才能還原
- `type` 可用 `glitch`、`flash`、`rgb`、`zoom`、`slow`、`ramp`、`shake`、`scan`、`text`、`trans`、`grade`、`sfx`、`other`

## 儲存專案

「匯出 → Koma 專案檔」會把原始版本和你的修改存成 `.koma-project.json`（快捷鍵 `Ctrl/⌘` + `S`）。下次在任何電腦上，把這個檔案和同一支成片一起匯入，就能接著剪，修改清單和畫面對照都跟存檔時一樣。檔案只記檔名、不含影片，所以成片要自己帶著。

「Koma 時間軸」（`.koma.json`）則只存改好的剪接版，適合交給 Claude 或當作定稿；用它重開時，修改清單會從零開始。

## 特效軌

特效依性質放在不同軌：電腦上是字幕、節奏（閃白、推近、慢動作、速度坡道、震動、轉場）、畫面（Glitch、RGB、掃描線、調色）、其他（音效、換畫面、其他）四軌。手機為了維持單一畫面，較高的手機三軌，較矮的兩軌。在電腦的空白軌上雙擊，會加一個那一軌的特效。

## 快捷鍵

| 按鍵 | 動作 |
| --- | --- |
| `空白鍵` | 播放 / 暫停（按鈕有焦點時也一樣，不會捲動頁面） |
| `J` `K` `L` | 倒退一秒 / 停止 / 播放 |
| `←` `→` `,` `.` | 前後一格（方向鍵加 `Shift` 一次 5 格） |
| `↑` `↓` | 上一個 / 下一個剪接點 |
| `Home` `End` | 跳到開頭 / 結尾 |
| `M` | 在播放頭加特效 |
| `I` `O` 或 `[` `]` | 把選取鏡頭的入點 / 出點設在播放頭 |
| `X` | 刪除播放頭這一格 |
| `S` | 在播放頭分割鏡頭 |
| `Delete` | 刪除選取的特效 |
| `Ctrl/⌘` + `S` | 儲存專案 |
| `Ctrl/⌘` + `Z` | 復原（加 `Shift` 重做） |

## 專案結構

```
index.html                     主程式（單一檔案）
examples/sample.koma.json      範例時間軸
tests/test.html                瀏覽器測試，開啟即執行，不會動到草稿
docs/reviews/                  圓桌審核報告
archive/cutdesk-prototype.html 前身「剪輯回饋台」，僅供參考
```
