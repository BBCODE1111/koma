# docs/reviews

這個資料夾是 **AITABLE 圓桌審核** 的交接處：各評審的獨立審核報告和佐證截圖放在這裡，Claude 在 Mac 上從這裡讀取，再決定修改和驗證。

## 檔名規則

- 報告：`aitable-<場次>-review-<commit 短碼>-<YYYYMMDD>.md`，例如 `aitable-004-review-e10781b-20261031.md`，代表針對 `e10781b` 這個版本、2026-10-31 的審核。
- 截圖：`aitable-<場次>-shots/`，報告用相對路徑引用。

## 注意

- 報告只記錄審核當下那個 commit 的狀態。之後的修正請另開新報告或複審，不要改舊報告。
- 「未驗證」代表評審沒辦法親自確認，需要有人實際測過才能當作事實。
- 只放報告和截圖；測試腳本、影片素材和匯出樣本不放進 repo。
